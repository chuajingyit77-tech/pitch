# 我要的水准

> 这是成品要达到的标准，归你所有。下面的规则是从你过去近三十个项目里写下来的话和做法中提炼的，**每一条都标着「待你确认」**：你说对，就改成「已确认」；你说不对，就删或改。Claude 不会不经你同意改这份文件。
>
> 强度「硬」＝不满足就不算完成；「软」＝默认照做，有理由可以例外。「来自」只写项目的类型，不写客户名字。

## 九、各类资料的完成标准

做到下面这些，这类资料才算完成（全部待你确认）。

| 资料 | 特有的完成标准 |
|---|---|
| 作战手册 | 每条异议都有答法，包括不舒服的；「收尾三句话」正好三句；有「绝对不要做的事」；会后 48 小时写到小时 |
| 一页简报 | 一页就是一页（精排不超过两页）；主张用对方的钱来讲；要对方做的是一小步，不是要预算 |
| 约见话术 | 每条只带一个链接；没有一句介绍公司的开场 |
| 演示稿 | 每页一个观点；来源页在最后；带演讲备注 |
| 演示样机 | 数据标明示意；离线能开；每个控件都有反应 |
| 战略备忘 | 「对方怎么想」写了对方给不了什么；谈判底线一节标内部用 |
| 会面一页纸 | 每格有分钟数和「定：」；先有长文才出一页纸 |
| 测算模型 | 每个假设单列；三种情景；能对上账；有「要你换成真数字的地方」 |
| 审核报告 | 先讲局限；先写说得好的再写缺口；最后一节直接回答你的问题 |
| 现场行动清单 | 每项有产出；每块有时限；合规底线单列 |
| 收费策略 | 第一句是答案；有定价红线；价钱都是你的决定或标了待确认 |
| 报价单 | 有编号、有效期、付款条件、签字栏；价钱全部经你确认 |
| 任务书 | 评测集是必须交付的一项；写了「交付时请说明」 |
| 验收标准 | 每条有坏例和好例；陌生人能判断 |
| 使用手册 | 章节按老板的顺序排；有「现在还没有的」；技术细节放在最后的附录 |
| 内容圣经 | 发布红线在正文之前；必须原样复用的块单独列出；先试播验收再做其余 |
