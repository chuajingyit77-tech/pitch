# 资料骨架

> 每一类项目默认出哪些资料、每份资料有哪些章节。`make-docs` 技能照这份文件做。你可以随时说「给这个项目加一个提案包」「以后方案包不要测算模型」，Claude 会改这里。

## 怎么读这份表

- **内/外**：内＝只给你看，放 `内部/`，标题下写「内部用，不外发」；外＝可以给别人，放 `对外/`，用读者的语言。
- **何时**：即时＝碎碎念落定后马上出初稿；条件＝条件成立才出；按需＝你开口才做（交付时会列成选项）；自动＝从别的资料汇总出来，不单独写。
- **骨架**：各节标题，用 ▸ 隔开，照原样用。给客户看的资料章节是英文。
- **限**：长度上限（待你确认）。

## 子类默认带哪些资料包

| 类型 | 子类 | 默认资料包 |
|---|---|---|
| 产品 | 套餐服务 | 基础 + 生意包 |
| 产品 | 数字产品 | 基础 + 产品包 |
| 产品 | 品牌与内容 | 基础 + 内容包 |
| 系统 | 内部系统 | 基础 + 系统包 |
| 系统 | 客户系统 | 基础 + 系统包（要卖给客户时再加提案包） |
| 系统 | 规范与能力 | 基础 + 《规则说明》 + 《任务书》 |
| 其他 | 提案 | 基础 + 提案包 |
| 其他 | 合作方案 | 基础 + 方案包 |
| 其他 | 审核 | 基础 + 审核包 |
| 其他 | 项目开发 | 基础 + 开发包 |
| 其他 | 营运计划 | 基础 + 生意包 |
| 其他 | 任务书 | 只出《任务书》 |
| 其他 | 研究笔记 | 只出《研究笔记》 |

给自己用的项目（`for_whom: 自用`）默认不出 `对外/` 资料。

## 基础包（每个项目都有）

| 资料 | 内/外 | 何时 | 骨架 |
|---|---|---|---|
| `卡片.md` | 内 | 即时 | 表头（现状）＋ 进展 ▸ 承诺 ▸ 期限 ▸ 决定 ▸ 备注 |
| `底稿.md` | 内 | 即时 | 一句话 ▸ 规格 ▸ 对方是谁、要什么、给不了什么 ▸ 主张与那个例子 ▸ 要对方做的那一步 ▸ 钱从哪里来 ▸ 做什么、不做什么 ▸ 红线与合规 ▸ 过关标准与停手线 ▸ 视觉方向 ▸ 长期要求 ▸ 变更记录 |
| `事实表.md` | 内 | 即时 | 表：编号｜说法｜数值｜性质｜等级｜来源｜核实日期｜可对外 ▸ 待确认（要你确认的／要问对方的／要查资料的） |

底稿是这个项目唯一的故事来源：主张、要求、价钱、红线，底稿里没有的，别的资料不能写。
