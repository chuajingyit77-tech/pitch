## 怎么写「验收标准」

验收标准不是任务描述，是**完成状态的照片**。

| ❌ 这样写没用 | ✅ 这样写才有用 |
|---|---|
| 「跟进 IIUM」 | 「一份 PDF：列出全部 HDJ 在手事项、每项的证据文件链接、8/26 当天谁交什么。缺证据的行必须标红。」 |
| 「处理 Blek 资产」 | 「资产清单逐项：询盘数、带看数、报价、已收订金金额。要有银行进账截图。」 |
| 「做 Demo」 | 「写下 Demo 的场景、设备、耗时、交付物样本。必须是能在客户面前重复第二次的东西，不是一次性表演。」 |

**判断标准：把这句话给一个不认识这个项目的人看，他能不能判断"交了"还是"没交"？** 不能，就还没写完。

## 每周重填的空表

```
姓名：
交付：
收入线：（Blek 止血 / HDJ 无人机 / 工厂数字化 / 大型项目 —— 四选一，不可为空）
验收标准：
截止：
```

**规则：**
1. 每人每周 **2–3 条**，不是 10 条。超过 3 条就没有优先级
2. 收入线不可为空。挂不上任何一条收入线的活，先问自己为什么要做
3. 验收标准不可为空，且必须能被外人判断
4. 派发时写好验收标准，**不要等交付回来才定义什么叫完成** —— 那是纠纷的来源
