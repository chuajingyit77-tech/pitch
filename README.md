| --- | --- |

| `idea-lab/` | Idea Lab: test a business idea with eleven Claude agents, each with one job (Board, Scout, Panel, Pricing, Offer, CFO, Marketing, Brand, Ops, Launch, Plan). Method from AI Sensei's reel ["This is how you actually test your business idea with Claude AI"](https://www.instagram.com/reel/DfWkNJZuFpJ/). Works in demo mode out of the box; add an Anthropic API key in Settings for a live run on `claude-opus-5-5`. |
