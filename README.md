## Prospek Cerah CRM

A lightweight single-user CRM lives in [`crm/index.html`](crm/index.html) — one file, no server, no login.

- **Dashboard** — shows what to do next: overdue follow-ups, tasks due today, leads with no next step, plus pipeline totals and recent activity.
- **Leads** — pipeline stages New → Contacted → Meeting → Proposal → Negotiation → Won / Lost, with deal values in RM, search, and stage filters.
- **Log updates** — after a meeting, call, or WhatsApp, open the lead, log what happened, move the stage, and set the next action with a due date.
- **Backup** — data is saved in the browser (localStorage); export/import a JSON backup from the Backup tab.

To use it: open `crm/index.html` in any browser, or enable GitHub Pages on this repo (Settings → Pages → deploy from branch) and visit `/crm/`.
