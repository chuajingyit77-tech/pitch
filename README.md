## 提案骨架

**商业模式（最重要）**

| 阶段 | 银行付多少 |
|---|---|
| 00 诊断 | **RM 0** —— 我方承担，4–6 周，交回双方签署的「可核验节省基线」 |
| 01 90天试点 | 一笔封顶费，在第二阶段**全额抵扣** |
| 02 推广 | **只从银行自己核验出的节省里分成**。某期没核验出，该期不收费 |

**保证**：第 90 天若银行自己测算不达标，差额由我方吸收。

**Track A · 八条既有成本线**
A1 楼宇检查 50–60% ／ A2 分行能源 18–25% ／ A3 设备维护 20–25% ／ A4 网点网络 10–15% ／
A5 安保值守 20–30% ／ A6 ATM 运维 ~60% ／ A7 抵押品评估 30–40% ／ A8 物业保险费 8–15%

> **A8 是关键一招**：拿 A1–A7 的风控数据去跟保险公司议价 —— 第八个模块是前七个的利息。

**Track B · 五条信贷损失路径**
B1 建筑贷款预警 ／ B2 不良与烂尾处置 ／ B3 抵押品持续监测 ／ B4 资本优化 ／ B5 反欺诈

**复利论证**：十三个模块共用一套采集层（无人机／卫星／IoT／固定相机／BIM-GIS）与一套技术底座
（数字孪生／GIS／AI／大数据风控／电子签章 PKI）。**第 13 个模块的成本只是第 1 个的零头。**

**技术方信用**：北京云星宇交通科技股份有限公司，北交所上市 **873806**，28 年，400+ 知识产权，
30 亿元合同额，覆盖 30 省，119 项软著，12 项国家级／省部级奖项。

**证据分级（必须保持）**：L1 已核验 ／ L2 合作方提供待核验 ／ L3 能力参考 ／ L4 内部测算。
外部案例数字一律标级，**绝不当作已实现成效呈现**。

## 源文件与构建

```
offer.html          主提案（由 parts/ 组装，勿直接改）
  parts/body.html     结构
  parts/app.js        数据 + 中英文 + 计算器
  parts/style.css     样式
  build.py            组装成 offer.html
dashboard.html      B1 操作台（单文件，直接改）
build_deck.js       生成 PPT
render_deck.py      把 PPT 渲染成图片来检查（本环境 LibreOffice 不可用）
build_pdf.py        生成一页 PDF
assets/img/         图片；*_scrim.jpg 是已烤入渐变的版本
OUTREACH.md         约见面话术
```

改完要跑：

```bash
python3 build.py          # 重新组装 offer.html
node build_deck.js        # 重新生成 PPT
python3 render_deck.py    # 渲染 + 几何检查（必须显示 geometry clean）
python3 build_pdf.py      # 重新生成一页 PDF
```

## 交付前必须验证（每一次）

1. 零 console 错误；桌面（1400px）与手机（390px）都零横向滚动
2. 计算器数值正确 —— 参考输入应得 **RM 18,230,000**
3. 中英切换后**已输入的数字不丢失**
4. PPT：`validate.py` 通过 **且** `render_deck.py` 报「geometry clean」**且**亲眼看过每一页
5. PDF：**只有一页**，且用 pymupdf 渲染出来亲眼看过

> 本环境限制：LibreOffice 与 pdftoppm 不可用；图片 CDN 被网关拦截（403）。
> 因此 PPT 用自建渲染器验证，PDF 用 pymupdf 验证 —— **不允许交付没看过的东西**。
