# LLM 议会 (LLM Council)

用户的问题：$ARGUMENTS
（如果上面为空，就用用户本条消息里除触发词以外的内容；仍然为空则先问一句"你想让议会讨论什么？"）

## 第 0 步：整理议题（不要跳过）
把用户的问题整理成一份**议题简报**，包含：
- 用户原话（逐字保留）
- 相关背景：如果问题涉及当前仓库/文件，先用 Read/Grep 读取相关内容，摘要放进简报
- 用户已知的约束（预算、时间、团队等，没提就写"未说明"）

所有议员拿到的是**同一份简报**，这样意见才可比较。

## 第 1 步：并行召唤 5 位议员
在**同一条消息里**发出 5 个 Agent 调用（必须并行，互相看不到对方意见，保持独立），`run_in_background: false`：

| subagent_type | 角色 | 视角 |
|---|---|---|
| `council-contrarian` | ① 反对者 | 假设计划有漏洞，直接抓出致命问题 |
| `council-first-principles` | ② 第一性原理者 | 你到底想解决什么问题 |
| `council-expansionist` | ③ 扩张者 | 不管风险，成功了能做多大 |
| `council-outsider` | ④ 局外人 | 假装不懂，抓出理所当然但别人看不懂的地方 |
| `council-executor` | ⑤ 执行者 | 不谈方向，只谈执行层面 |

每个调用的 prompt = 议题简报全文 + "请严格按你的角色设定输出，用用户提问的语言回答。"

## 第 2 步：主席汇总
等 5 位全部返回后，调用一次 `council-chairman`，prompt 包含：
- 议题简报
- 五位议员的**完整原文**，分别用 `## ① 反对者` … `## ⑤ 执行者` 标题隔开

## 第 3 步：呈现给用户
按这个顺序输出：
1. **主席报告**（完整，放最前面——这是用户最需要的）
2. 一个折叠区，标题"📜 议员原始发言"，里面依次放五位议员的意见（每位可精简到要点，但不要改变立场）

不要在主席报告之外再加你自己的长篇总结。
