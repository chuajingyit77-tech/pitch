# 关系：一个机构或一个人一张卡

## 0. 先过隐私闸门

关系资料默认是「内部」。仓库公开时这些卡片不会被备份，会话结束就消失。**第一次要记关系资料时，先用一句话告诉老板**（办法见 `backup` 技能）；他说照记，就记，并在交付里再提醒一次没备份。

## 1. 建卡之前先找

在 `关系/机构/`、`关系/人/` 里按名字和 `aliases` 搜。没有再建：

```
python3 tools/wos.py new org --name "机构名" --kind 潜在客户
python3 tools/wos.py new person --name "称呼" --kind 潜在客户 --org "机构名"
```

`kind`：客户 · 潜在客户 · 原厂技术方 · 合作伙伴 · 机构大学 · 政府 · 供应商 · 团队 · 投资人 · 个人 · 自家

| 键 | 用法 |
|---|---|
| `role` | 这个人在对方那里管什么、在这件事里是拍板的、把关的、还是传话的 |
| `pipeline` | 只给客户和潜在客户：新线索 · 已联系 · 会面中 · 已报价 · 谈判中 · 合作中 · 沉睡 |
| `tier` | A／B／C，他定 |
| `cadence_days` | 多少天联系一次。他没说时先不填，问一次：A 级两周、B 级一个月、C 级一季度，行不行 |
| `last_contact` `next_contact` | 上次、下次联系日 |
| `projects` | 相关项目的名字；项目卡片的 `orgs`、`people` 里也写上对方的名字 |

## 2. 记一次往来

他说「今天跟某某通了电话，他说……」：

1. 记往来（哪天发生的就写哪天；会自动更新上次联系日）：
   `python3 tools/wos.py log "林经理" 往来 "电话｜要点一句话｜下一步" --date 2026-11-25`
2. 约了下次、或关系往前走了：`python3 tools/wos.py set "林经理" next_contact=2026-12-05 pipeline=已报价`
3. 双方答应的事（「下周」这类说法换算成具体日期）：
   - `python3 tools/wos.py log "林经理" 承诺 "我答应 把报价单发过去" --date 2026-12-02`
   - `python3 tools/wos.py log "林经理" 承诺 "对方答应 帮忙约财务负责人" --date 2026-12-04`
   做完了：`python3 tools/wos.py done "林经理" "报价单"`。**他答应别人的事到期，会变成「急」的提示。**
4. 涉及某个项目的，那张项目卡也记一行：`python3 tools/wos.py log "项目名" 进展 "……" --by 老板 --date 2026-11-25`
5. `python3 tools/wos.py check`，再 `build`、`backup`。

## 3. 什么可以记，什么不记

- 记：对方在乎什么、怎么做决定、偏好和忌讳、谁介绍的、双方答应过什么。
- 你的推断要写明是推断：`- 推断：真正拍板的是财务，不是他。（待核实）`
- 不记：证件号、银行账号、健康、宗教、家庭隐私；听来的负面说法不当事实写。
- 谈判底线、成本、报价策略不放关系卡片，放那个项目的 `内部/` 资料里。

## 4. 「该联系谁」

```
python3 tools/wos.py nudges
```

把关系类的提示列出来，每个人给一句可以直接用的开场（按上次往来写，不寒暄）。只是草稿：**没有他点头，不发任何消息**；他要邮件草稿，就放进草稿箱，不发送。
