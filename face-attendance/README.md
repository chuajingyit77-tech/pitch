# 人脸考勤系统（旧 Windows 电脑 + 摄像头）

把一台旧电脑放在公司门口的柜台，接一个摄像头对着门口：员工进出时看一下摄像头，系统就会**自动认人、自动打卡、自动算工时**。老板在手机或其他电脑上就能看到今天谁来了、谁迟到、每个人工作了几个小时，还能导出 Excel。

```
   门口                柜台
  ┌────┐   👤 →   [摄像头] ── USB ── [旧电脑：自动识别 + 记录]
  │    │                                    │  公司 WiFi/网线
  └────┘                                    ├── 老板手机：今日概况 / 报表
                                            └── （可选）云端 Google 表格
```

## 功能

| 功能 | 说明 |
|---|---|
| 自动识别打卡 | 员工走到门口看一眼摄像头，约 1 秒完成；连续识别 3 次才算数，防止误认 |
| 自动区分进 / 出 | 每天第 1 次 = 进入（上班），第 2 次 = 离开，第 3 次 = 再进入……（午饭、外出都能算） |
| 防重复 | 同一个人 3 分钟内重复出现不会重复打卡（可调） |
| 每次打卡都拍照 | 每条记录都有现场抓拍照，方便核对、防代打卡 |
| 陌生人抓拍 | 不认识的人出现会被拍下来，在「今日概况」里能看到 |
| 自动算工时 | 每段「进入→离开」时间相加；自动标记 **迟到 / 早退 / 漏打下班卡** |
| 报表导出 | 按任意日期范围导出 CSV，Excel 直接打开（中文不乱码） |
| 手机查看 | 同一网络下手机打开后台网址即可（需要密码） |
| 手动补卡 | 员工忘记打卡、摄像头坏了，管理员可补录 |
| 云端同步（可选） | 每条打卡实时推送到 Google 表格 / 你们自己的系统；断网会排队，恢复后自动补发 |
| 签到屏 | 柜台屏幕全屏显示：实时画面、时钟、"早上好，张三 ✓ 打卡成功"，还会语音播报 |

全部数据保存在这台电脑本地（`data` 文件夹），不需要付费、不需要联网也能用。

---

## 一、需要准备的东西

- **旧电脑**：Windows 7 / 8 / 10 / 11 都可以，4GB 内存以上，双核 CPU 就够（识别时会自动缩小画面，旧电脑也跑得动）。
- **USB 摄像头**：普通 1080p 网络摄像头就行（例如罗技 C270/C920，100–300 元）。笔记本自带摄像头也能用。
  也支持网络摄像头（IP Camera），见下面「设置」。
- 电脑能上网（**只在安装时需要**，之后断网也能正常打卡）。

### 摄像头怎么摆（很重要，决定识别准确度）

1. **高度**：大约 1.5–1.7 米（人脸高度），稍微向下倾斜一点点。
2. **距离**：让员工经过时脸离摄像头 **0.5–2 米**。最好把摄像头放在员工进门后**必经、会正面看过来**的位置（比如柜台上正对门口）。
3. **光线**：**不要背光**——摄像头不要对着玻璃门/窗户外的阳光，否则人脸会黑。门口光线暗的话加一盏灯。
4. 在门口地上贴一个「请看摄像头 👀」的小标志，效果最好。

## 二、安装（只需要做一次）

1. **安装 Python**：到 <https://www.python.org/downloads/> 下载安装。
   - Windows 10 / 11：装最新版即可。
   - **Windows 7：只能装 Python 3.8**（<https://www.python.org/downloads/release/python-3810/>，选 *Windows installer*）。
   - ⚠️ 安装第一个画面一定要勾选 **“Add Python to PATH”**。
2. 把整个 `face-attendance` 文件夹复制到电脑上，例如 `D:\face-attendance`。
3. 双击 **`install.bat`**，等它跑完（会自动安装需要的软件并下载人脸模型，约 40MB）。
   - 如果在国内网络下载很慢/失败，按提示用清华镜像重试。
4. 打开 `config.json`（右键 → 用记事本打开），**至少改这三项**：
   - `"company_name"`：公司名字
   - `"admin_password"`：管理后台密码（一定要改！）
   - `"work_start"` / `"work_end"`：上下班时间，例如 `"09:00"` / `"18:00"`

## 三、每天使用

1. 双击 **`start.bat`**。会出现一个黑色窗口（**不要关掉它**），几秒后浏览器会全屏打开签到屏。
2. 想要开机自动启动：双击一次 **`autostart.bat`** 即可。
3. 建议在 Windows 设置里把这台电脑的 **睡眠** 改成「从不」，屏保关掉。

## 四、登记员工（第一次使用）

1. 在柜台电脑（或手机）打开 **管理后台**：黑色窗口里会显示网址，例如 `http://192.168.1.20:8000/admin`，输入密码。
2. 点 **员工** → 填姓名（工号、部门可选）→ **添加员工**。
3. 进入员工页面，让员工站在**柜台摄像头前**，点 **📸 拍照登记**。
   **建议每人拍 3–5 张**：正脸、稍微左转、稍微右转、戴眼镜/不戴眼镜、戴口罩的话也拍一张。
   也可以直接上传员工证件照（清晰正脸即可），但用现场摄像头拍的效果最好。
4. 登记完，让员工走到门口试一次，签到屏会显示 “早上好，xxx ✓”。

> 系统会自动检查：如果把 A 的脸登记到了 B 名下，会提示“这张脸和 A 很像”，防止登记错人。

## 五、查看考勤

| 页面 | 看什么 |
|---|---|
| **今日概况** | 谁在公司、谁已离开、谁还没来、谁迟到；今天的陌生人抓拍 |
| **打卡记录** | 每一次进出的时间和抓拍照；可以删除错误记录、手动补卡 |
| **考勤报表** | 选日期范围（默认本月）：每人出勤天数、总工时、迟到/早退次数；**⬇ 导出 Excel** |

在同一个 WiFi 下，老板手机浏览器打开 `http://<柜台电脑IP>:8000/admin` 就能看。

### 想在公司外面也能看？

最简单的方法：在柜台电脑和你的手机上都安装 **Tailscale**（免费，<https://tailscale.com>），登录同一个账号，之后在任何地方都能用 Tailscale 给的地址打开后台。**不建议**直接在路由器上做端口映射暴露到公网。

## 六、设置说明（config.json）

| 设置 | 默认 | 说明 |
|---|---|---|
| `camera_source` | `0` | 摄像头编号。电脑有多个摄像头时试 `1`、`2`。网络摄像头填 RTSP 地址，如 `"rtsp://admin:密码@192.168.1.64:554/stream1"` |
| `work_start` / `work_end` | `09:00` / `18:00` | 上下班时间，用来判断迟到、早退 |
| `late_grace_minutes` | `5` | 迟到宽限分钟数（9:05 前到都不算迟到） |
| `match_threshold` | `0.42` | 识别严格程度。**认错人** → 调高到 0.45–0.5；**老是认不出** → 先多登记几张照片，再考虑调低到 0.38 |
| `min_face_size` | `60` | 人脸小于多少像素就不识别（避免远处路过的人被打卡） |
| `confirm_hits` | `3` | 连续认出几次才打卡 |
| `cooldown_minutes` | `3` | 同一人多少分钟内不重复打卡 |
| `process_every_n_frames` | `3` | 每几帧识别一次。电脑很卡就改成 5 |
| `save_unknown_faces` | `true` | 是否抓拍陌生人 |
| `webhook_url` | 空 | 云端同步地址，见下一节 |
| `port` | `8000` | 网页端口 |

改完 `config.json` 后，关掉黑色窗口，重新双击 `start.bat` 生效。

## 七、连接云端系统（可选）

每次打卡，系统会把下面这样的数据 POST（JSON）到 `webhook_url`：

```json
{"id": 12, "company": "我的公司", "employee_id": 3, "emp_no": "A001", "name": "张三",
 "department": "销售", "type": "IN", "time": "2026-10-27 09:01:33", "day": "2026-10-27",
 "score": 0.71, "note": ""}
```

断网时记录会先存在本机，网络恢复后自动补发，不会丢。

### 方法 A：同步到 Google 表格（免费、5 分钟搞定）

1. 新建一个 Google 表格 → 菜单 **扩展程序 → Apps Script**。
2. 把里面的代码全部换成：

   ```javascript
   function doPost(e) {
     var d = JSON.parse(e.postData.contents);
     var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheets()[0];
     if (sheet.getLastRow() === 0) sheet.appendRow(['时间', '姓名', '工号', '部门', '进/出', '相似度', '备注', '记录ID']);
     sheet.appendRow([d.time, d.name, d.emp_no, d.department, d.type === 'IN' ? '进入' : '离开', d.score, d.note, d.id]);
     return ContentService.createTextOutput('ok');
   }
   ```
3. 点 **部署 → 新建部署 → 类型选「网页应用」**，“谁可以访问”选 **任何人**，部署。
4. 复制得到的网址（`https://script.google.com/macros/s/.../exec`），填到 `config.json` 的 `webhook_url`，重启。

### 方法 B：接你们自己的系统 / HR 软件

让 IT 提供一个接收 POST JSON 的接口地址，填到 `webhook_url` 即可；字段如上。

## 八、常见问题

**签到屏一直显示“打不开摄像头”**
→ 检查 USB 是否插好；关闭其他正在用摄像头的软件（微信视频、Zoom 等）；把 `camera_source` 改成 `1` 试试。

**某个员工老是认不出来**
→ 给 TA 用柜台摄像头多拍几张（不同角度、戴眼镜/口罩各一张）；检查门口是否背光。

**员工忘记打下班卡**
→ 报表里会标「漏打下班卡」，当天工时只算到最后一次离开。管理员可以在「打卡记录 → 手动补卡」补上。

**会不会被照片骗过？**
→ 本系统没有活体检测，理论上举着手机照片可能被认成本人。但每次打卡都有**现场抓拍照**，代打卡一查就知道。如果需要更高安全性，可以换用带活体检测的商用考勤机。

**数据怎么备份？**
→ 所有数据都在 `data` 文件夹里（`attendance.db` + 照片）。定期把整个 `data` 文件夹复制到 U 盘或网盘即可。换电脑时，把整个 `face-attendance` 文件夹（含 `data`）复制过去就能接着用。

**黑色窗口里有 `[ WARN ] ... setPreferableTarget` 这样的英文**
→ 正常现象，可以忽略。

## 九、隐私提醒

人脸属于**个人敏感资料**。使用前请：
- 书面告知员工系统的用途（考勤）、保存哪些资料、保存多久，并取得员工同意；
- 在门口张贴「此区域设有人脸识别考勤摄像头」告示；
- 员工离职后在后台删除其人脸照片；
- 遵守当地法律（例如马来西亚《2010 年个人资料保护法》PDPA、新加坡 PDPA、中国《个人信息保护法》等）。

### 技术说明（给 IT 看）

- Python + Flask（waitress）+ OpenCV，SQLite 存储，无需 GPU。
- 人脸检测：YuNet；人脸识别：SFace（128 维特征，余弦相似度），均为 OpenCV 官方模型（`download_models.py` 自动下载到 `models/`）。
- 识别时画面缩小到 640 宽，默认每 3 帧识别一次。
- 文件：`app.py` 网页与路由 · `engine.py` 摄像头与识别 · `db.py` 数据库与工时计算 · `sync.py` 云端推送。
- 柜台本机（localhost）可以免密码打开签到屏；后台所有页面都需要密码。
