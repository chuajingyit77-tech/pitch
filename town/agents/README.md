# 镇上的 66 位检查员

每一位只做一件事。一份文件交进来，按它的类型挑出该看的人，每人给一条结论。

- 规则层 11 位：不用模型，不花钱
- 规则+模型 4 位：规则定不了才问模型
- 模型层 51 位：需要模型

换模型只影响模型层的判断深度，不影响谁查什么、查几项。这是这套系统能换便宜模型的原因。
