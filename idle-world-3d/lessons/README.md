# 守护者的课 · 怎么放进公司自己的 SOP

世界里的动物守护者（现在是锦鲤池的**老苍鹭**）会像游戏里的 NPC 一样，用对话和选择题教东西。
所有课程内容都在 `lessons/index.js` 这一个文件里，改这个文件就能换课、加课，不用动别的代码。

## 一节课长什么样

```js
complaint: {
  title: '接待投诉的四个字',          // 课名（「学习」面板和守护者的菜单里显示）
  keys: '听 · 认 · 办 · 跟',          // 一行关键词（金色）
  about: '客人带着火气来投诉时……',      // 一句话简介
  minutes: 3,                         // 大约几分钟
  badge: '接待之道',                   // 学完得到的徽章
  reward: { kind: 'ogon', name: '金麟', what: '黄金锦鲤' },  // 第一次学完，池里多一条这样的锦鲤
  steps: [
    { say: '守护者说的一句话。用 **两个星号** 包起来的字会变成金色。' },
    {
      ask: '题目：客人一开口就说……你会怎么回？',
      options: [
        { text: '选项一', reply: '选了它，守护者解释为什么不好' },
        { text: '正确的选项', ok: true, reply: '答对时守护者说的话' },
        { text: '选项三', reply: '……' },
      ],
    },
    { card: { title: '要点 · 接待投诉', items: [['听', '一句话说明'], ['认', '……']] } },
  ],
  outro: '最后一句话。',
},
```

- `say`：守护者说话，点一下屏幕继续。
- `ask`：选择题。选错了，守护者解释为什么不好，然后同一道题再问一次（错的选项会划掉）。
  第一次就答对的题越多，星星越多（全对 ★★★）。
- `card`：要点卡。学完以后，在「学习」面板里点「要点」随时可以再看，适合当作 SOP 速查。
- 课程在守护者的 `lessons` 列表里，顺序就是菜单里的顺序。
- `demo: true` 的课会标上「示范」。换成公司自己的内容后，删掉这一行。

## 换成公司的 SOP

1. 打开 `lessons/index.js`，照着上面的格式，把每一份 SOP 写成一节课：
   先用几句 `say` 讲清楚步骤，每一两步配一道 `ask`，最后一张 `card` 总结。
2. 把新课的 id 加进守护者的 `lessons: [...]` 里。
3. 改完运行 `python3 idle-world-3d/tools/build_standalone.py`，iPad 会自动更新到新内容。

也可以把 SOP 原文交给 ChatGPT / Codex，并附上这句话：

> 请把下面这份 SOP 改写成 idle-world-3d/lessons/index.js 里 LESSONS 的一节课：
> 口吻是一只沉稳、爱用池塘和水打比方的老苍鹭；先用 4–8 句 say 讲清楚步骤，
> 中间放 2–3 道 ask 情景选择题（每题 3 个选项，只有一个 ok: true，每个选项都写 reply 解释），
> 最后一张 card 要点卡（每条一个关键字 + 一句话）。只输出这一节课的 JS 对象。

## 进度存在哪里

每台设备的浏览器各自记住学到哪里、几颗星、得了哪些徽章（和喂鱼记录存在一起）。
一节课中途关掉，下次会从停下的地方接着讲。
