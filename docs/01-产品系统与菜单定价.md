- 甘梅 RM 12.9 是**心理入场价**（菜单上让人觉得"不贵"），但收银话术永远推 1/2/3 号

## 4. 二度炸的运营含义（为什么这个工艺适合你的结构）

1. **一炸在中央厨房完成**（定型、锁汁、灭菌）→ 冷藏 3 天 / 冷冻 30 天，配送半径大
2. 前线**二炸 90–120 秒**即出餐 → 档口和餐车不需要会腌肉的师傅，兼职可上手
3. 二炸后外壳更脆、持脆时间更长 → **外卖和打包场景不塌**，这就是外卖评分护城河
4. 未售完的一炸半成品可退回/调拨 → 浪费趋近于零

## 5. 品控红线

- 一炸后中心温度、冷却时限、标签日期：中央厨房出货单必检
- 前线油每日测极性值（或按炸量表强制换油）——脆度就是产品，油坏=产品坏
- 酱包/粉包只用中央厨房定量包，**前线禁止自行调酱**（口味一致性 = 品牌）
- 辣度标识统一（不辣/小辣/大辣），芥末款菜单上标警示（这也是营销点）
