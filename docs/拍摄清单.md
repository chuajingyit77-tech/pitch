# 上门拍摄清单（一家店 20 分钟拍完）

> 用途：给 High priority 客户免费剪的那条"敲门砖"视频。
> 器材：手机就够。竖屏 9:16 拍，开 4K/60fps（慢动作用），擦干净镜头。

## 必拍 12 个镜头（照顺序拍，每个 10–20 秒）

| # | 镜头 | 怎么拍 | 为什么 |
|---|------|--------|--------|
| 1 | 招牌菜特写 | 镜头贴近食物，慢慢移动（推近或平移） | 封面/开头 hook |
| 2 | 冒烟/滋滋声 | 刚出锅那一刻，拍烟和声音 | 3秒留住观众的就是这个 |
| 3 | 淋酱/倒汤/拉丝 | 慢动作拍（60fps） | 全网最吸睛的镜头类型 |
| 4 | 大火炒锅 | 侧面拍师傅颠锅、火苗 | 动感+专业感 |
| 5 | 夹起来那一口 | 筷子夹起食物对镜头 | 观众代入感 |
| 6 | 老板/师傅讲一句话 | "我在这里做了XX年，这道菜..."（10秒就够） | 有人味才有转发 |
| 7 | 店面外观+招牌 | 从马路走向店门（walk-in 镜头） | 让人认得出位置 |
| 8 | 店内人气 | 饭点拍坐满/排队（拍背影，避开正脸） | 社会认同 |
| 9 | 价格牌/菜单 | 拍清楚招牌菜价钱 | 评论区一定有人问价钱 |
| 10 | 制作过程一个细节 | 手工步骤：包、切、烤、捞 | "原来是这样做的" |
| 11 | 顾客吃的反应 | 熟客愿意的话拍一句"好吃！" | 真实感（要先问过） |
| 12 | 老板招手/比赞收尾 | "来 Seremban 一定要来吃！" | 结尾 call-to-action |

## 拍摄小规则

- **每个镜头拍 2 次**，一次稳一次近，回来好挑
- **横竖都别混**：全程竖屏
- **别用手机变焦**：走近拍，变焦画质会烂
- **收音**：老板讲话那段离 1 米内拍，环境炒菜声就用手机原声
- 全程 20 分钟内搞定，不打扰做生意 —— 这本身就是你的卖点

## 拍完怎么给 Claude 剪

1. 把素材直接丢进 Claude Code 的对话（或放进 repo/网盘给个路径）
2. 告诉我：店名、招牌菜、价钱、想发的平台（TikTok/小红书/Reels）
3. 我来做：
   - 挑出每段最好的 2–3 秒，剪成 30–45 秒成片（ffmpeg）
   - 自动上字幕（中文/马来文/英文都行），字体大小按手机屏优化
   - 转 9:16、调色、加转场、控制节奏（前 3 秒必须是镜头 2 或 3）
   - 出封面图 + 3 个标题文案 + hashtag
   - 需要的话：AI 配音/配乐、AI 补 B-roll、预测这条片的爆款潜力
4. 你收到成品 mp4，检查一遍就能发
