# 第18节 — 现场行动清单(下一步)

> 适用情形:开发方已在项目当地(玻璃市 Padang Besar / 吉打邻区);关系方表示可取得执照;EPC 可垫资(EPC+F);投资方已有意向。
> 原则:**先文件、后承诺;先独家地位、后引荐资源。** 本清单与 Section 11(尽调)、Section 12(业主问题)配套使用。

## 1. 证据包(最优先,目标 1–2 周内完成)

### 执照(逐项书面确认)
- [ ] 执照种类:保税仓(Customs Act 1967 s.65)/ 自由商业区 FCZ(Free Zones Act 1990)/ 口岸或码头运营权 / 货运代理牌 / 其他?
- [ ] 发牌机关:JKDM(关税局)/ 财政部 / 州政府 / 其他?
- [ ] 持牌主体:以谁的名义?可否转入项目 SPV?
- [ ] 附带条件:马方持股要求、土著股权要求、履约条件、期限
- [ ] 目前状态:已发出 / 已批复待发 / 口头承诺?——**取得任何书面凭证**

### 土地
- [ ] 地段号与面积;土地局查册(业主、用途类别、明示条件、限制)
- [ ] 有无抵押、查封、地役权;是否涉铁路保留地 / 州地 / 马来保留地
- [ ] 拟议取得方式:买断 / 长租 / 土地入股?价格与条件

### 关系方与项目主
- [ ] SSM 公司查册:注册信息、股东、董事、有无诉讼与欠税
- [ ] 关系方与项目的**法律关系**书面说明(地主?获授权开发人?代理?)
- [ ] 既有协议(MOU / JV / 委托书)全套复印件

## 2. 锁定 Prospek 的法律地位(引入 EPC 与投资方之前)

- [ ] 签署 NDA
- [ ] 签署**独家开发授权 / Heads of Terms**,至少载明:
  - Prospek 角色:项目开发方、联合体组建方、PMO、数字化伙伴(见 Section 7)
  - 独家期(建议 6–12 个月)及续期条件
  - 费用与股权原则(金额可留待可研后定,原则先锁定)
  - 保密与不可绕开条款(non-circumvention)
- [ ] 明确项目主授权谈判人及决策流程

## 3. 现场工作(在地期间完成)

### 踏勘记录(拍照 + GPS 定位)
- [ ] 地块全貌、边界、现状占用
- [ ] 到 KTMB 铁路线 / Padang Besar 站 / PIP 的实际距离与路线
- [ ] 进出道路等级与桥涵限载;到 Changlun 高速口车程
- [ ] 供电杆线与变电设施位置;水源;电信
- [ ] 排水与积水痕迹(雨季风险)
- [ ] 边境卡口实况:清晨与 21:00 截关前的货车排队长度各记录一次
- [ ] Perlis Inland Port 外围考察:闸口流量、堆场使用观感

### 会谈(能约几个是几个;此阶段只建立关系、不谈条件)
- [ ] 项目主正式会谈 —— 议程即 Section 12 的 26 个问题;当场移交 Section 11 文件清单
- [ ] 州政府 / MB Inc(州务大臣公司)
- [ ] NCIA(北部走廊执行机构)
- [ ] KTMB(北区 / 货运)
- [ ] JKDM 关税局(Padang Besar)
- [ ] 与 PIP / Mutiara Perlis 的关系定位初探(整合 / 互补 / 竞争 —— 见 Section 1 战略问题)

## 4. EPC 垫资(EPC+F)结构要点

- [ ] 现阶段只签**框架性 MOU**;土地与执照文件到手前,不签带金额与义务的垫资协议
- [ ] 结构走 SPV:马来西亚项目公司持地持照,EPC 合同与还款安排均落在 SPV
- [ ] 股权红线:港口/战略特许**马来西亚方 ≥51%**(交通部长 2026 年 7 月重申)+ 物流牌照的土著股权条件 —— 股权表从第一天按此设计
- [ ] 中方承包商内部审批所需材料提前准备:可研、还款来源分析、业主资信、合规审查(NDRC/MOFCOM/SAFE 及集团内控)
- [ ] 垫资的还款来源必须指向:项目收入 / 再融资 / 投资方进场 —— 三选一并写清楚

## 5. 合规底线(不可妥协)

- [ ] 执照取得路径必须合法、可向银行与国企尽调完整披露
- [ ] 任何涉及公职人员的安排,须经得起 MACC(马来西亚反贪会)与中方央企反腐审计的检视
- [ ] 所有关联交易(Prospek 服务、EPC 合同)按市场基准披露 —— PKFZ 是本走廊的前车之鉴(R79)

## 6. 顺序与产出

```
证据包(1–2周) → 独家授权(2–4周) → 快速可研+PIP定位研究(4–8周)
   → 三方条款书:项目主 / EPC / 投资方(8–12周) → Gate G1 去/留决策
```

产出物:红旗报告(Red Flag Report)+ 证据包 + 独家授权书 —— 有了这三样,现有的 EPC 垫资与投资意向才能转为有约束力的条款书。
