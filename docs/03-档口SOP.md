# 03 · 档口 SOP

> 档口定位：稳定日销现金流 + 全菜单体验店 + 零售酱/粉/冷冻包的出货口。
> 前线只做四个动作：**二炸 → 裹酱/撒粉 → 加料 → 出餐**。

---

## 1. 硬性红线（月度检查，破线必须动手术）

| 项目 | 红线 |
|---|---|
| 租金 / 营业额 | ≤ 15% |
| 人工 / 营业额 | ≤ 25% |
| Food cost | ≤ 35% |
| 饮料/加购附加率 | ≥ 60% |

任何一条连续 2 个月破线 → 改菜单结构 / 改班表 / 换位置，不硬撑。

## 2. 每日流程

### 开档前（60 分钟）

1. 收中央厨房货：核对出货单、查标签日期、量冷链温度 → 签收
2. 油温预热 + 测油质（极性值试纸或按换油表）
3. 酱包隔水回温、粉罐补满、配料盒补满（先进先出）
4. 收银 float、POS、外卖平台上线
5. 按昨日同星期销量 ±20% 设定当日备货基准

### 营业中

- 二炸 90–120 秒（听声/看色 + 计时器双确认），高峰期保持滚动出锅
- 出单顺序：先杯装底 → 撒粉/裹酱 → 加料 → 插签/贴标 → 叫号
- 收银固定话术（每单必讲，写进培训）：
  1. "要不要加 RM 2.9 配饮料？"（combo）
  2. "加 RM 1 多一个炸蒜/葱头酥？"（topping 上翻）
  3. 结账时指一下货架："今天这个酱有瓶装，带一瓶回家？"（零售）
- 外卖单：杯盖打孔透气 + 酱另包（保脆），这是外卖评分的关键

### 收档（30 分钟）

1. 未拆封半成品清点 → 记录 → 冷藏（3 天内用完）或标记退回中央厨房
2. 废弃量记录（什么、多少、为什么）——损耗必须有名字
3. 日报 5 个数字：营业额 / 单量 / 客单价 / 附加率 / 废弃额，10 分钟填完发群
4. 清洁 checklist 拍照打卡

## 3. 备货与浪费控制

- 一炸鸡按「基准量 + 高峰前补货点」管理，宁可高峰前等 5 分钟，不可下午囤一堆
- 酱包/粉/配料全部定量包装 → 理论用量 = 单量 × 配方量，每周对一次账，
  差异 > 5% 就查（偷吃、手重、漏记，都会现形）
- 与餐车共享库存池：餐车退回的货次日档口优先消化

## 4. 人员配置

- 平日 2 人（炸台 1 + 收银/组装 1），周末高峰 3 人（加 1 机动）
- 新员工培训 = 半天：看 SOP 视频 → 试做 10 杯 → 老手验收签字
- 前线**没有任何调味决策权**，一切按包、按量、按表
