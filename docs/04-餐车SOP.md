# 04 · 餐车 SOP

> 餐车定位：获客机器 + 高流量场收割 + 预售 catering 利润锁定。
> 餐车亏钱只有一个原因：去了不该去的场。所以本 SOP 第一条是接单规则，不是做菜。

---

## 1. Go/No-Go：接不接这个场（最重要的一页）

### 单日出车成本（按真实数字更新此表）

```
摊位费            RM 150–300
人工 2 人          RM 200
油/气/车耗/损耗     RM 80
────────────────────────
单日固定成本 ≈ RM 500
综合毛利率 ≈ 62%（按 04 菜单结构）
保本营业额 = 500 ÷ 0.62 ≈ RM 810 ≈ 50 单
```

### 规则

- **预估营业额 < 保本线 × 1.5（约 RM 1,250 / 75 单）→ 不去。**
- 预估依据：主办方历史人流数据、同行摊主上届营业额、自己的场地记录档
- 没有数据的新场 = 「试场」：备货减半、只去一次、结果记档
- 天气预报下雨概率 > 60% 的露天场：备货 −40% 或改期
- **餐车宁可停在家，也不去烂场。不出车 = 不亏钱。**

### 场地评分档（每场必填，半年后这就是你最值钱的资产）

| 字段 | 内容 |
|---|---|
| 场地 / 日期 / 天气 | |
| 摊位费 | |
| 营业额 / 单量 / 客单价 | |
| 当日净利 | |
| 评分（净利 ≥ RM 400 = A；200–400 = B；< 200 = C） | |

**同一场地连续 2 次 C → 拉黑。** 排期永远优先 A 场。

---

## 2. 预售化：让一半的出车日先收钱再出车

- **企业/学校/活动包场**：谈最低消费（如 80 份 × RM 15），收 50% 订金才排期
  → 出车前利润已锁定
- **私人活动**（生日/公司 event）：按人头报价，比摆摊价高 20–30%
- 目标：每月出车日 ≥ 50% 是「订金已收」的场。做到这点，餐车月度几乎不可能亏。
- 获客入口：车身印「包场请扫码」+ 档口放小卡 + 每场活动发 100 张名片

---

## 3. 出车执行

### T-1 天

- [ ] 确认场次 / 时间 / 电源 / 天气
- [ ] 按场地档案定备货量（新场 = 保本量 × 1.2）
- [ ] 中央厨房按单打包：一炸鸡（分装袋，贴日期）、4 款酱包、粉罐、配料盒、饮料
- [ ] 车检：油、气瓶余量、发电机、冰箱温度、POS/收款码、零钱 float RM 200

### 当天

- 提前 90 分钟到场：30 分设备 → 30 分 mise en place → 30 分缓冲
- 只卖 4 SKU + 饮料（见 01 菜单），**现场不接任何自由搭配**
- 分工固定：A = 炸台，B = 收银 + 组装 + 推 combo；目标出餐 ≤ 2.5 分钟/单
- 高峰前 30 分钟开始滚动预炸，排队 > 8 人时 B 提前收单报号
- **收尾前 90 分钟盘点一次**：预计卖不完 → 启动清货 bundle
  （"最后 X 份，combo 减 RM 3"），底价 ≥ 成本 × 1.5——清货是回血不是白送

### 收车 15 分钟（当天完成，不过夜）

1. 未拆封半成品清点装箱 → 次日退回中央厨房或调给档口
2. 填单日 P&L：营业额 − 货成本 − 摊位费 − 人工 − 油气 = **当日净利**
3. 填场地评分档
4. 收到的包场询问当晚回复报价

## 4. 餐车月度看板

| 指标 | 目标 |
|---|---|
| 单场平均净利 | ≥ RM 400 |
| 场地命中率（A+B 场占比） | ≥ 70% |
| 预售场占比 | ≥ 50% |
| 出车日废弃率 | ≤ 5% |
