## 一、结论先行

**无人机课题定为：空地协同的散果时效感知与回收调度（GroundTruth）。**

不做清洗、不做测绘、不做喷洒 —— 这三项已被彻底商品化。做的是把无人机变成地面捡果机器人的**眼睛和调度大脑**，产出「散果密度 + 落地天数」的地图，输出可审计的作业指令。

## 二、四个支撑判断

### 1. 钱在 OER，不在「捡得多」

| 数字 | 值 | 用途 |
|---|---|---|
| 散果含油率 | >40%（按重量） | 价值锚点 |
| 全国整串 OER | 19.86%（2023） | 对比基准 |
| 每 1% OER | RM47.39 / 吨 FFB（2025 均价） | **把「多捡」换算成钱的系数** |
| 散果占总产量 | 5–10% | 规模 |
| 采收+运输环节损失 | 总产量的 3–7% | 可回收空间 |
| 全国劳工缺口 | 约 40,000 人，过半在采收与园内收集 | 痛点 |
| 捡果工月薪 | RM800–1,000（法定最低 RM1,700） | 全园最不受欢迎工种 |
| 全行业机械化率 | 约 10.88% | 空白程度 |

⚠️ **不要引用「散果每年值 RM1 billion」** —— 多处二手转引，找不到一手出处。

### 2. 真正的学术空白：落地时间

- 新鲜未损伤果：FFA < 0.3%
- 挤压后：伤口 FFA 1 小时内飙升，**最快的生成发生在前 15 分钟**
- 损伤 + 潮湿：**第 5 天 FFA 达 10.44%**（商业规格通常 ≤5%）
- 未捡散果还会发芽成杂草，产生除草成本

**公开文献中不存在任何一项马来西亚田间研究，把「落地第 N 天 → FFA X% → 折价 RM Y/吨」打通。** 现有 FFA 数据全部来自实验室挤压/浸水实验。

这个缺口同时是：学术新颖性 + 商业定价依据 + 数据护城河。

### 3. 空地协同是被作物物理结构逼出来的

- 果串长在**冠层之下**，且**最熟的果串位于冠层最低处** → 俯视几乎完全遮挡，全球的空中判熟研究都卡在这里
- MPOB 自己的 Bt 航喷试验：幼虫 28 天降 96%，但**仍记录到约 64.5 蛹/叶** → ImageJ 证实上表面覆盖优异、**叶背沉积不足**

油棕最值钱的两个问题（判熟、叶背施药）都是「**空中看不见、地面走得到**」。

**检索不到任何已发表的「油棕园 UAV + UGV 协同系统」。** 零件齐了但没人拼：
- ForaNav（2025, arXiv:2503.02275）— 针对**油棕树**的 MAV 穿冠导航，不依赖 GPS
- 香蕉园 UAV 先验引导 UGV 路径规划（2026, *Comput. Electron. Agric.*）— 热带、地面受限，同构
- 蜜柚园 UAV-UGV 协同靶喷（IJABE）

### 4. 法规上的降维打击

| | 喷洒类 | 感知类（我们选这个） |
|---|---|---|
| 企业资质 | **必须持 UAWC**（CAD 6011 Part II） | 不需要 |
| 飞手 | RCoC-B + **Module 2 (AGR)** | RCoC-B |
| 农药 | 必须在 **DOA 批准的无人机可施用清单**内 | 不适用 |
| 机型分类 | 满载常 >20kg，监管加重 | ≤20kg，Small Unmanned Surveillance Aircraft |
| 每次飞行 | ATF，提前 **14 个工作日** | 同左 |

Aonic 是 2025 年 1 月才拿到 UAWC 的。**选感知 = 从最重的监管档掉到最轻的档，几周内就能合法开飞。**

**IIUM 不是 CAAM 认证的 RPTO，也不持 UAWC** → 合规飞行能力是我方在合作中不可替代的筹码。

## 四、出海路径

### 进入顺序（反直觉）

1. **马来西亚**（补贴 + 案例 + 痛感最高）
2. **PNG** — 园区就是 SD Guthrie / KLK 的海外资产，**同一个决策者，获客成本接近零**
3. **哥伦比亚** — 60.9 万 ha，**Fedepalma 一个协会 = 75 个 palmero 核心区 + 8,000 生产者的单一入口**；86% 正规就业（人工成本高且逐年涨）；74% 中小生产者；无本地含量壁垒
4. **印尼** — 面积 16.83M ha（马来西亚 3 倍）但工资低 → ROI 分子小；且 **TKDN 本地含量 ≥30%** 才能进 PTPN 国企与政府采购（Terra Drone 做到 31.26% 才拿证）→ **必须合资建组装线**

**推迟**：泰国（户均 0.64–0.8 ha，碎片化到卖不动机器）、尼日利亚（外汇管制是最大隐性壁垒）、欧盟（Directive 2009/128/EC 第 9 条**原则禁止**航空施药；地面机器人 2027-01-20 起受机械法规 (EU) 2023/1230 约束，AI 承担安全功能者**禁止自我声明**，须公告机构认证）

### 第二作物：澳洲坚果

- 2024 全球带壳产量 339,200 t；南非 27%、中国 20%、澳洲 16.5%、肯尼亚 8.2%
- 澳洲自 1990 年代起已机械化（finger-wheel / sweeper）→ **证明了机器可行**
- 但**南非、肯尼亚、中国云南、越南仍大量人工捡拾**（南非案例：200 ha 雇 100 名临时工，3–8 月）
- 次选：椰子（印尼/菲律宾，客户重叠度最高，但单果价值低，只能走服务队模式）

**明确避开**：杏仁、核桃、山核桃、橄榄、栗子 —— Flory、Exact、Savage、FACMA、Monchiero 已把地面收集做成商品机械，AI 在平整果园里没有边际价值。
**可可**：果荚不落地，地面收集不适用；仅无人机分析可迁移。

### 商业模式

**跨境速度排序：授权经销商 > 服务承包商特许 > 整机+SaaS >> 自营 RaaS**

**绝不在海外自营机队**，直到该国已有 >20 台在跑且有本地维修合伙人。

反面证据（必须内化）：
- **FarmWise** 融资 US$65M 后 2025-04 关闭 —— 死因：机器对农户资本强度过高
- **Abundant Robotics**（苹果采摘）2021-07 停业
- **Small Robot Company** 清算
- **Naïo** 纯硬件，融 US$33M 后被迫重组、放弃服务模式
- 2025 年全球近 20 家 agtech 停业

正面模板：
- **Rantizo** hub-and-spoke：turnkey 包 US$40–50k 卖给承包商，承包商收 US$15–20/acre，**4–6 周回本**
- **Blue River → John Deere US$305M**（买的是视觉模型）
- **Prospera → Valmont US$300M**（**零硬件业务**）
- **Aerobotics**：8,100 万棵树 + 100 万柑橘的标注数据集，18 国运营

### 定价公式（可无摩擦跨境复制）

```
服务费 = 多回收散果吨位 × 当地 CPO 价 × 分成比例
```

各国 CPO 价都挂钩 MYR / CIF Rotterdam，**不需要为每个国家重做定价模型**。

⚠️ **已知风险**：分成模式要求园主接受我方对「本来有多少散果」的测量。这正是无人机存在的理由，但也是信任问题。**缓解**：初期可先按固定 RM/ha + 效果保证，等测量方法被工厂交货重量验证过再转分成。

### 签约前必争的 10 项（内部用，不外发）

1. **Background IP 清单化写入附件** —— 预训练模型、代码库、数据管线、机身设计逐项列明，空白附件 = 事后灾难
2. **Foreground 归属**：首选公司拥有 + 大学保留非商业教研许可；退让方案是大学拥有但公司获**全球、独占、可再许可、含改进**的许可，**费率与里程碑在签 RCA 时一并敲定**
3. **绝不接受「许可条款日后另行商定」** —— 项目做完后大学议价权最大，这是马来西亚产学合作最常见的坑
4. **避免共有** —— 共有人实施/许可通常需全体同意 = 一票否决。若不可避免，必须写明各方可独立实施与再许可、无需另一方同意、无需分账
5. **数据所有权单列条款**（大学模板通常没有）：原始影像 / 标注 / **模型权重** / 衍生数据集 / 园区敏感数据 分别定义归属。争取：原始 + 标注 + 权重归公司，大学获限定学术用途非独占许可、不得再分发原始数据
6. **发表禁令**：投稿前 60–90 天审阅，可延长至专利递交；**务必把学位论文纳入**，包括 irep.iium.edu.my 自动收录的例外约定
7. **学生 IP 转让**：马来西亚大学的学生不是雇员，成果不自动归属任何一方 → 所有接触项目的学生、RA、实习生逐人签 IP 转让 + 保密，作为项目启动的先决条件
8. **上游资助条款回溯冲突**：GET / PPRN / NTIS / CRDF / IMGS 各带 IP 与收益分享条款 → **先取得资助合约文本，再定 RCA**
9. **地域写 worldwide**，再许可权明确覆盖关联公司、分销商与本地合资实体。仅写 Malaysia 会在出海时被迫重谈
10. **人员绑定与存续**：锁定 PI，约定离职接续；终止后已产生的许可不得回收

**注意大学侧的动机张力**：商业化成绩计入 MyRA，直接影响大学排名 → 大学既有强烈动机签约，也有强烈动机把 IP 记在自己名下。要预判。

## 九、一个尚未回答的问题

**可获取的无人机是什么级别？** 只有 RGB / 农业作业级（T30/T50）/ 可挂多光谱与热成像？
